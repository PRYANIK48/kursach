# Roguelike Game

Курсовой проект по дисциплине «Программирование».

## Описание проекта

Данное приложение представляет собой двумерную игру жанра roguelike, разработанную на языке программирования C++ с использованием графической библиотеки SFML 2.

Игрок управляет персонажем, исследует последовательность игровых комнат, сражается с противниками и проходит уровни. В игре реализованы система столкновений, стрельба снарядами, генерация комнат на основе шаблонов и пользовательский интерфейс, отображающий состояние персонажа.

## Основные возможности

* управление персонажем;
* сражение с противниками;
* система снарядов;
* генерация игровых комнат;
* пользовательский интерфейс;
* подсчёт пройденных комнат;
* отображение характеристик персонажа.

## Используемые технологии

* C++
* SFML 2
* Visual Studio 2022

## Управление

| Клавиша    | Действие        |
| ---------- | --------------- |
| W, A, S, D | Перемещение     |
| F          | Выстрел         |
| R          | Перезапуск игры |

## Сборка проекта

1. Установить Visual Studio 2022.
2. Установить библиотеку SFML 2.
3. Открыть файл решения (`.sln`).
4. Выполнить сборку проекта.
5. Запустить приложение.
